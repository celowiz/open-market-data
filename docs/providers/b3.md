# B3 equities, derivatives, and OTC credit

Ingests simplified EOD files from Pesquisa por Pregão: equities last trade
(BVBG.186.01) and derivatives official settlement (BVBG.187.01). The same
command also fetches Boletim Diário OTC consolidated prints for debêntures /
CRI / CRA when B3 publishes them.

Current operational flags (temporary): `public_api_enabled=true`,
`redistribution_policy=API_ONLY`, `public_dataset_enabled=false`. Quotes may
appear on `/v1/quotes`; they must not be published as Parquet. ADR-0014 still
applies to bulk/public datasets. Re-ingest (`marketdata ingest b3`) updates an
existing `b3` source row.

## Download

```text
https://www.b3.com.br/pesquisapregao/download?filelist=SPRE{YYMMDD}.zip
https://www.b3.com.br/pesquisapregao/download?filelist=SPRD{YYMMDD}.zip
https://www.b3.com.br/pesquisapregao/download?filelist=IN{YYMMDD}.zip
POST https://arquivos.b3.com.br/bdi/table/export
```

- `SPRE` → BVBG.186.01 PriceReport (`LastPric` → `LAST`)
- `SPRD` → BVBG.187.01 PriceReport (`AdjstdQt` → `OFFICIAL_SETTLEMENT`)
- `IN` → BVBG.028.02 instrument master (`EqtyInf` and `FutrCtrctsInf`)
- BDI table `ConsolidatedRecords` → OTC consolidated trades (`Closing` / Último Preço → `LAST`)
- BDI table `InstrumentRegistration` → OTC cadastro (CREDIT universe)

Outer ZIP contains an inner ZIP containing XML. Empty B3 responses are HTTP 200
with a 22-byte ZIP (`PK\x05\x06`) and must be rejected (`PK\x03\x04`, size ≥ 100).
The inner 187 ZIP may contain two near-duplicate XML files; settlement parsing
dedupes by ticker and date. The inner 028 ZIP is the same pattern (~0.6GB XML
twice); master parse walks the first XML only.

HTTP uses a bounded `httpx.Timeout` (15s connect, read ≥ 60s idle). Optional
files (187, 028, BDI credit) that time out are skipped; 186 still fails the run.

`INGEST_UNIVERSE=scratch` (or an explicit equity CSV) filters BVBG.186 LAST
persist to the allowlist, skips live BDI OTC credit, and attaches 028 ISINs
only for tickers already persisted that day. Empty universe still persists the
full 186 file and live credit. Ingest logs stage timings (download/parse/persist)
to stderr.

Safe ingest clock for 187 is after 20:30 America/Sao_Paulo. An empty 187 file
does not fail the 186 portion of the same run; retry later. Missing or empty
OTC credit tables are also best-effort and do not fail equities/derivatives.

## Commands

```bash
uv run marketdata ingest b3 --date 2026-08-21
uv run marketdata backfill b3 --start 2024-01-01 --end 2026-08-24
uv run marketdata backfill b3 --start 2020-01-01 --end 2026-08-24 --cotahist
```

Daily ingest is one trading date. `backfill_b3` walks every calendar day in
`start`..`end`, skips Saturday/Sunday (and checkpoints those skips so resume
does not retry them), and treats an empty Pesquisa por Pregão ZIP
(`B3ParseError` “not a usable ZIP”) as `empty_days` rather than failing the
range. Daily `ingest b3` still fails on that empty ZIP. Credit prints stay on
the per-day ingest path (no `/v1/credit`). Polite delay between live HTTP days
defaults to 0.5s (0 when a provider is injected, as in tests).

Postgres `COMMIT`s after each completed calendar day (successful ingest,
weekend skip, or empty-ZIP skip) so a 6-hour GitHub Actions cancel keeps
already-finished days. A failed day rolls back only that day. The object-store
checkpoint (`state/backfill/b3.json`) lives on the runner’s `./data` when
`OBJECT_STORAGE_BACKEND=local` and does not survive between workflow runs;
resume across jobs relies on idempotent quote upserts, not that file.

Pesquisa por Pregão is **not** a 20-year BVBG archive. Recent official EOD is
BVBG.186/187 (and 028 master). Deep listed-equity history is opt-in COTAHIST.

Equities identity is ticker (`PETR4`) plus `B3_SECURITY_ID`. Futures identity is
ticker (`DI1F27`) plus `B3_SECURITY_ID`. ISIN and futures `maturity_date` are
attached from BVBG.028.02 when present.

Credit identity is Código IF / `TckrSymb` (`JALL14`) plus ISIN when the OTC
cadastro publishes it. Do not invent `B3_SECURITY_ID` for this file. Asset class
is `credit`; instrument type is `debenture`, `cri`, or `cra`.

Phase 6 persists official settlement only for:

```text
^(DI1|DOL|WDO|WIN|IND)[FGHJKMNQUVXZ]\d{2}$
```

`AdjstdQt` is stored as the quote value with `unit=PU`. `AdjstdQtTax` is copied
to quote metadata. `LastPric` is never stored as settlement (on DI1 it is the
last traded rate, not the official PU).

Coverage prices B3 equities as `LAST` and listed WIN/IND/WDO/DOL/DI1 contracts
as `OFFICIAL_SETTLEMENT`. See [`COVERAGE.md`](../COVERAGE.md).

## COTAHIST (opt-in backfill)

Annual ZIP (HTTP, then HTTPS if needed):

```text
http://bvmf.bmfbovespa.com.br/InstDados/SerHist/COTAHIST_A{YYYY}.ZIP
```

Inner file is fixed-width text. Only register type `01` is parsed as a quote.
Header `00` and trailer `99` are ignored. `PREULT` (positions 109–121) is an
`N(11)V99` implied-decimal field: two decimal places, persisted as `PriceType.LAST`
via `exact_decimal` (never IEEE `float`). Currency is `BRL`. `is_official=true`,
source `b3`. Artifact filename is `COTAHIST_A{YYYY}.ZIP`; quote `extra` records
`origin=COTAHIST` and `source_field=PREULT`.

**COTAHIST is not BVBG.186.** Do not map `PREULT` or `LastPric` to
`OFFICIAL_SETTLEMENT`. This file is not a derivatives settlement archive; do
not invent DI/DOL/WDO/WIN/IND settlement from it.

If the same ticker and date already has a BVBG.186 `LAST`, existing
`upsert_quote` revision rules apply (new artifact bytes can bump `revision`).
Do not convert a COTAHIST row into a different `price_type`.

`INDOPC` (position 202) is the layout’s “indicador de correção de preços de
exercícios ou valores de contrato” for options and secondary forward markets
(attached table: `1` USD, `2` TJLP, `8` IGPM, `9` URV). It is **not** an
exclude-this-row flag. Rows are not dropped because `INDOPC` is non-zero, and
`INDOPC` is never used to change `price_type`. The value is copied to `extra`.

When the same ticker and date appear more than once (for example vista `TPMERC=010`
and fracionário `020`), backfill keeps the vista (`010`) row.

## OTC credit prints

Primary public prints are the Boletim Diário export of **Negociação consolidada
(Balcão)** (`ConsolidatedRecords`), not BVBG.186 and not Pesquisa por Pregão
“Renda Fixa Privada”.

- Filter `InstrumentCode` / `InstrumentType` to `DEB`, `CRI`, `CRA`,
  `CRI PÚBLICO`, `CRA PÚBLICO`. Ignore CDB, LF, COE, and RF ETFs here.
- Persist `Closing` (friendly name Last Price / Último Preço) as
  `PriceType.LAST` via `exact_decimal`. The JSON field is named Closing; it is
  **not** `PriceType.CLOSE`.
- Persist a quote only when Último Preço is present and `NumberOfTrades` > 0
  (or quantity > 0 if the row omits trade count).
- Do **not** persist `ReferencePrice` / Preço de Referência as the quote value
  (copy to `extra` only). That field is B3 MtM or VWAP, not a print.
- Do **not** ingest Pesquisa por Pregão `RF{DDMMYY}` `PU_MERCADO` as `LAST`.
  That bulletin mixes traded averages and model/reference prices (Manual de
  Apreçamento de Debêntures). CALC / UP2DATA Debêntures MTM are paid and out
  of scope.
- Do **not** use BVBG.186 `LastPric` for credit. 186 is equities.
- Multiple grouping rows (vista/termo, INTRAGRUPO/EXTRAGRUPO) collapse to one
  `LAST` quote per instrument and date. Prefer `extra` from `EXTRAGRUPO`.
- Cadastro (`InstrumentRegistration`) upserts CREDIT instruments even when
  that IF has no print. On a weekday, when the trades file was published and
  an IF has no usable Último Preço, insert `quality_events` with
  `event_type=NO_PUBLIC_PRICE` and `severity=INFO`. Do not write a quote row
  (no zero, no stale last, no reference PU). Skip absence events if the trades
  file is missing or empty (holiday / not published yet).
- Token names `OTCTradeInformationConsolidated` / `OTCInstrumentsConsolidated`
  return HTTP 400 after the 2026-01-19 BDI migration. Use the BDI table export
  POST above. Do not bypass captcha or login if access controls appear.

## API

```text
GET /v1/quotes/PETR4
GET /v1/quotes/PETR4/latest
GET /v1/quotes/PETR4/history?source=b3
GET /v1/quotes/DI1F27
GET /v1/quotes/DI1F27/latest
GET /v1/quotes/DI1F27/history?source=b3
GET /v1/quotes/DI1F27?source=b3&price_type=OFFICIAL_SETTLEMENT
GET /v1/quotes/JALL14
GET /v1/quotes/JALL14?source=b3
GET /v1/quotes/{ISIN}
```

Equities and credit `price_type` is `LAST`. Futures settlement `price_type` is
`OFFICIAL_SETTLEMENT`. There is no `/v1/credit` route. Public Parquet of B3
remains disabled.
