# B3 equities and derivatives (BVBG.186 / BVBG.187)

Ingests simplified EOD files from Pesquisa por Pregão: equities last trade
(BVBG.186.01) and derivatives official settlement (BVBG.187.01).

Current operational flags (temporary): `public_api_enabled=true`,
`redistribution_policy=API_ONLY`, `public_dataset_enabled=false`. Quotes may
appear on `/v1/quotes`; they must not be published as Parquet. ADR-0014 still
applies to bulk/public datasets. Re-ingest (`marketdata ingest b3`) updates an
existing `b3` source row.

## Download

```text
https://www.b3.com.br/pesquisapregao/download?filelist=SPRE{YYMMDD}.zip
https://www.b3.com.br/pesquisapregao/download?filelist=SPRD{YYMMDD}.zip
https://www.b3.com.br/pesquisapregao/download?filelist=IN{YYMMDD}.zip
```

- `SPRE` → BVBG.186.01 PriceReport (`LastPric` → `LAST`)
- `SPRD` → BVBG.187.01 PriceReport (`AdjstdQt` → `OFFICIAL_SETTLEMENT`)
- `IN` → BVBG.028.02 instrument master (`EqtyInf` and `FutrCtrctsInf`)

Outer ZIP contains an inner ZIP containing XML. Empty B3 responses are HTTP 200
with a 22-byte ZIP (`PK\x05\x06`) and must be rejected (`PK\x03\x04`, size ≥ 100).
The inner 187 ZIP may contain two near-duplicate XML files; settlement parsing
dedupes by ticker and date.

Safe ingest clock for 187 is after 20:30 America/Sao_Paulo. An empty 187 file
does not fail the 186 portion of the same run; retry later.

## Commands

```bash
uv run marketdata ingest b3 --date 2026-08-21
```

One command is one trading date. Multi-year BVBG loops, empty-ZIP handling, and
optional COTAHIST (equities only; different semantics from 186) are **Phase 12**
`marketdata backfill b3`.

Equities identity is ticker (`PETR4`) plus `B3_SECURITY_ID`. Futures identity is
ticker (`DI1F27`) plus `B3_SECURITY_ID`. ISIN and futures `maturity_date` are
attached from BVBG.028.02 when present.

Phase 6 persists official settlement only for:

```text
^(DI1|DOL|WDO|WIN|IND)[FGHJKMNQUVXZ]\d{2}$
```

`AdjstdQt` is stored as the quote value with `unit=PU`. `AdjstdQtTax` is copied
to quote metadata. `LastPric` is never stored as settlement (on DI1 it is the
last traded rate, not the official PU).

## API

```text
GET /v1/quotes/PETR4
GET /v1/quotes/PETR4/latest
GET /v1/quotes/PETR4/history?source=b3
GET /v1/quotes/DI1F27
GET /v1/quotes/DI1F27/latest
GET /v1/quotes/DI1F27/history?source=b3
GET /v1/quotes/DI1F27?source=b3&price_type=OFFICIAL_SETTLEMENT
```

Equities `price_type` is `LAST`. Futures settlement `price_type` is
`OFFICIAL_SETTLEMENT`. Public Parquet of B3 remains disabled.
